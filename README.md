# honua-sdk-js

JavaScript/TypeScript SDK workspace extracted from `honua-io/honua-server` (issue #336).

Repository layout:
- `js/` - core JavaScript/TypeScript SDK package
- `mcp/` - MCP server package for Honua tooling integration
- `.github/workflows/` - CI workflows for this repository

The `js/` and `mcp/` subfolders are intentional package boundaries, not migration leftovers.
