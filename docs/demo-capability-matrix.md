# Demo Capability Matrix

Status vocabulary:

- `demoed`: exercised by a sample app or browser smoke lane.
- `tested-only`: covered by fixtures or unit/integration tests, but not yet surfaced in a user-facing sample.
- `blocked`: coverage depends on follow-up work outside this PR-sized slice.
- `not-in-scope`: intentionally excluded from the current demo harness, usually because it is platform/tooling behavior rather than app UX.

This matrix tracks demo coverage for issue #70. The implementation-level
protocol defaults stay in `docs/protocol-capability-matrix.md`; this document
answers where a reviewer can see or smoke each capability.
