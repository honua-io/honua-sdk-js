The field-instrument standard for every sample

One identity for the whole portfolio: chart-paper and basalt surfaces, a single Honua-green accent, and a monospace register voice for everything the UI reads out — coordinates, statuses, field labels. Every specimen below renders from tokens.css + components.css in both themes.

Color

Semantic tokens only — samples never reference hex. Text pairs meet WCAG AA on their documented surfaces (ratios in README.md); input borders and focus rings clear the 3:1 non-text minimum.

Typography

Three voices, all system stacks (samples are network-isolated): a display face for headings, the UI sans for prose, and the monospace register for data readouts. The register — uppercase, letterspaced, 11px — is the identity carrier; use it for eyebrows, table headers, badges, and field labels only.

Cartography

On-map data layers use the openly licensed thematic ramps (CARTOColors CC-BY-4.0, viridis CC0) — never the UI chart series. The board shows each ramp on the theme's basemap land tone. Rules that are not optional: the basemap stays desaturated so saturation is reserved for data; at most 6–7 categorical hues at once; and every text run over the canvas carries a halo in the local basemap tone.

Focus & keyboard
