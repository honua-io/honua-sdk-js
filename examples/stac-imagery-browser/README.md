# Find recent Maui imagery

Fixture-backed **Walkthrough** for one product job: search a bounded Maui STAC API, page through its results, render a selected preview, and continue through the SDK surface that understands the chosen asset.

The Walkthrough uses the merged `@honua/sdk-js/stac` client rather than reimplementing catalog traversal. Its deterministic transport proves:

- Maui bounds, time, collection, cloud cover, fields, and sort constraints.
- GET and POST Item Search with relative server-provided pagination.
- Cancellation of a pending page and missing-extension tolerance.
- Format and role filtering before the signed-URL refresh hook.
- Typed handoffs to `@honua/sdk-js/cog`, `@honua/sdk-js/pmtiles`, `@honua/sdk-js/columnar-workflow`, and `@honua/sdk-js/raster`.
- Signed PMTiles v3 inspection through the authenticated client pipeline with exact 206 range, byte-budget, cancellation, recovery, and auth-redacted trace evidence.

The app displays its logical request, signing trace, and bounded PMTiles inspection beside the result. It does not mount the PMTiles renderer descriptor or claim vector-tile painting; the separate `pmtiles-static` project remains that renderer proof. This is deterministic browser evidence, not a claim that a live Honua STAC service was contacted. The broad `connect({ protocol: "stac" })` adapter remains supported; this dynamic task facade remains experimental.

## Atomic Example

The complete bounded search and selection is isolated in [`src/dynamic-stac-example.ts`](./src/dynamic-stac-example.ts):

```ts doc-test=skip reason="continues a caller-created DynamicStacClient and shows only the atomic task body"
const response = await stac.search({
  method: "POST",
  collections: ["sentinel-2-l2a"],
  bbox: [-156.75, 20.55, -155.85, 21.05],
  datetime: "2026-04-01T00:00:00Z/2026-05-05T23:59:59Z",
  filterLang: "cql2-json",
  filter: { op: "<=", args: [{ property: "eo:cloud_cover" }, 20] },
});

const asset = await stac.selectAsset(response.features[0], {
  roles: ["visual", "data"],
  formats: ["cog"],
});
```

Use the [search STAC and open an asset walkthrough](../../docs/walkthroughs/search-stac-and-open-assets.md) for deployment, pagination, signing, and format-specific execution decisions. The [complete project](https://github.com/honua-io/honua-sdk-js/tree/trunk/examples/stac-imagery-browser) includes the browser UI, deterministic transport, and Playwright evidence.
