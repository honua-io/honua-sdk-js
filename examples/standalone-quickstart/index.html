Honua JS SDK / Standalone

Query a public GeoServices endpoint and render it on MapLibre — no Honua server.

This app points the SDK at a public Esri FeatureServer, turns it into a MapLibre geojson source with one call, and re-runs the same query through the drop-in FeatureLayerCompat (the esri-leaflet migration path). Zero API keys, zero account, zero Honua infrastructure.
